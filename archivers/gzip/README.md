# FreeBSD gzip (20190107)

NetBSD/FreeBSD `gzip` for Braam: writes RFC 1952 gzip (hand-built header and raw
deflate); reads gzip, bzip2, xz, lzip, zstd, and Unix `.Z`. Pack (`.pack`) is
disabled here (`NO_PACK_SUPPORT`).

## Using it

After `pkg install gzip`, commands `gzip`, `gunzip`, `zcat`, and `gzcat` are the
same binary. Compress with `gzip file`; decompress with `gzip -d` or `gunzip`.

## What changed

Same shape as [archivers/zip](../zip/): `PORT NOFLOAT`, Group B `b_*` I/O,
codec cores left as plain C++. Upstream `gzip.c` and helpers are converted via
`tools/convert.py` and `tools/fix_body.py` into `gzip_body.inc.cpp`; the driver
is `braam.cpp`, CLI in `gzip_cli.cpp`, `.Z` in `zcompress.cpp`, lzip in
`unlz_fd.cpp` (generated by `tools/gen_unlz.py`).

| Upstream | Braam |
| --- | --- |
| `main` / `exit` | `gzip_main` / `co_return` status |
| `getopt_long` | Hand-rolled options in `gzip_cli.cpp` |
| `read`/`write`/… | `read_retry`, `write_retry`, `b_*` |
| `fts` `-r` | `b_opendir` / `b_readdir` |
| `copymodes` | No-op (store has no mode/owner/mtime) |
| `SIGINFO` | No-op |
| `SIGINT` + temp file | `sig_catch` + unlink `remove_file` |
| `.Z` `funopen` | `zuncompress_fd` in `zcompress.cpp` |
| lzip `fdopen` | Memory-backed decoder in `unlz_fd.cpp` |

## Build and test

`make` builds `build/archivers/gzip/gzip.wasm`. Regenerate the body after
upstream edits:

```
cd archivers/gzip && python3 tools/convert.py && python3 tools/fix_body.py
python3 tools/gen_unlz.py
```

Tests: `archivers/gzip/test/*.mjs` (see top-level `make test`).

## Files

- `braam.cpp`, `braam.h` — process entry, I/O retries, diagnostics
- `gzip_cli.cpp` — options and `gzip_main`
- `gzip_body.inc.cpp` — generated gzip core and bzip2/xz/zstd helpers
- `zcompress.cpp`, `unlz_fd.cpp` — `.Z` and lzip
- `tools/` — conversion scripts
